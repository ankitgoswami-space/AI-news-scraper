## 7. Git Visibility Strategy

**DO:**
- Profile README with bio + top projects
- 6 pinned repos (best projects only)
- Each project README with screenshot + demo + setup
- 3-5 meaningful commits/week (real work)
- Active recent activity (last 60 days)

**DON'T:**
- Fake daily commits ("chore: update README")
- Trivial projects (To-Do app, weather app)
- Empty repos or orphan projects
- Force-pushing to fake history

**Rule:** Consistency > Volume. 3 real commits > 10 fake ones.
