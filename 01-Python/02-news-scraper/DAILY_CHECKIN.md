# Daily Check-In Ritual

**Ye har baar padho jab bhi kaam shuru karne aao. 30 seconds.**

---

## The 4 Questions

### 1. Aaj kya karna chahta hoon?
_[Ek line me likho]_

### 2. Ye North Star se align hai?
- [ ] Haan — Priority Stack (Section 8) ka part hai
- [ ] Haan — Kisi portfolio project (Section 9) ka part hai
- [ ] Haan — Skills learning (Section 10) ka part hai
- [ ] Haan — Job applications ya visibility
- [ ] Nahi — Yeh naya feature hai, sochna padega
- [ ] Nahi — Yeh random kaam hai

**Agar Nahi tick hua → STOP. Reconsider.**

### 3. Iska job-hunting impact kya hai?
_[Ek line — "X interviews unlock honge" ya "Y applications better honge" ya "Z skill seekhunga"]_

**Agar koi clear impact nahi → SKIP this task.**

### 4. Last 7 days me progress kya hui?
- Applications bheji: ___
- Interviews aaye: ___
- Meaningful commits: ___
- Blog/LinkedIn posts: ___
- Skills seekhe: ___ hours

**Agar teeno me se koi bhi 0 hai → red flag. Aaj usko address karo.**

---

## Red Flags (turant ruk jao)

- ❌ "Ye feature cool lagega" — cool ≠ job
- ❌ "Aur ek chart add karun" — charts kaam nahi dilate
- ❌ "Refactor karna chahiye" — kaam pe kaam, no visible progress
- ❌ "Documentation perfect karni hai" — good enough > perfect
- ❌ "Blocked hoon, kuch aur karta hoon" — blockage solve karo, escape nahi
- ❌ "Kal se serious ho jaunga" — aaj se serious ho

---

## Green Lights (aage badho)

- ✅ ATS Optimizer me kaam
- ✅ Referral Finder me kaam
- ✅ Application Tracker me kaam
- ✅ Master refresh script
- ✅ Naya portfolio project (RAG, Agents, ML Deploy)
- ✅ Blog post likhna
- ✅ LinkedIn post
- ✅ Job applications bhejna (minimum 5)
- ✅ DSA practice
- ✅ Interview prep

```
   [1 line]

   Applications: __ | Interviews: __ | Commits: __ | Blog: __ | Learning: __ hrs

Decision: [GO / RECONSIDER / SKIP]
```

---

## Weekly Reset (Every Sunday, 15 min)

**Yeh 3 sawaal:**
1. Is week kitne applications bheje? Kitne interviews?
2. Kitne meaningful commits? Kitna seekha?
3. Kya block hua? Kya fix karna hai?

**Agar 2 hafte se 0 applications OR 0 interviews → Emergency Protocol (Section 15).**

**Agar 3 hafte se 0 interviews → Pivot Strategy:**
- Referral strategy double
- Resume review
- Skills gap diagnosis
- Target companies change
